ITEP 414 – Week 2 Portfolio Project
Enterprise Infrastructure Planning for a Startup Company
Project Overview

This project is about creating an IT infrastructure plan for ABC Startup Solutions, a newly established software development company with 20 employees. The company needed a complete infrastructure plan before purchasing equipment, setting up a network, and deploying IT services.

The project covers the company's company profile, hardware and software requirements, network infrastructure, network topology, system administration roles, infrastructure recommendations, and personal reflection.

Learning Objectives

Through this project, I learned how to:

Identify the IT needs of a small company
Plan and organize hardware, software, and network resources
Create a basic enterprise network topology
Understand different system administration roles
Document an IT infrastructure plan
Make practical recommendations for a company's IT setup
Company Scenario

ABC Startup Solutions is a software development company with one office floor and 20 employees.

Department	Employees
IT	5

Enterprise Network Diagram

The planned network follows a centralized setup. The internet connects to the ISP modem, router, firewall, and managed switch. The switch connects the server, printers, wireless access point, and the computers used by the IT, HR, Finance, and Sales departments.

Challenges Encountered

The most challenging part of the project for me was creating the enterprise network diagram. I had to think carefully about how the devices should connect and where each part of the network should be placed. I had to make sure the topology made sense instead of simply putting the devices wherever they looked good.

Reflection

This project helped me understand that planning an enterprise infrastructure can be difficult and requires careful thinking. I learned that an infrastructure plan is like a blueprint because it shows how the different parts of a company's IT system work together.

The project also helped me understand why planning is important before deploying an IT system. It is similar to building a house because the plan and foundation need to be strong before everything else can be built.

Overall, this project gave me a better understanding of system administration and helped me practice planning, network design, documentation, and technical decision-making.
